Dokumen padat untuk referensi cepat. Dilampirkan oleh Lesson 001.

Konsep inti: standar S3 API

Hampir semua penyedia object storage memakai S3 API (satu set operasi HTTP: PUT objek, GET, DELETE, list bucket, signature untuk auth). Karena itu, kode yang menulis ke satu penyedia bisa dipindahkan ke penyedia lain hanya dengan mengganti endpoint + kredensial — tanpa menulis ulang logika aplikasi.

Glosarium (dipakai konsisten di semua lesson)

Object storage
Penyimpanan "blob" (file) dengan metadata, diakses via HTTP, skalabel. Cocok untuk PDF skripsi yang tidak sering diubah.
Bucket
Kontainer/penampung objek di dalam satu penyedia (mis. simtas-documents, simtas-archives).
S3 API
Standar antarmuka HTTP object storage (asli AWS S3), diadopsi banyak penyedia → portabilitas.
Presigned URL
URL sementara yang memberikan akses unduh ke objek privat selama X detik, tanpa membocorkan kredensial. SIMTAS pakai ini untuk download dokumen (15–30 menit).
Egress
Transfer data keluar dari penyedia (biaya tersembunyi utama object storage).
Class A / Class B ops (istilah R2)
Operasi yang mengubah state (tulis) vs hanya membaca. Tulis lebih mahal daripada baca.
Strategy Pattern / Dependency Injection
Pola menukar implementasi di balik satu interface; inilah yang membuat storage SIMTAS bisa diganti lewat StorageService.
Self-hosted
Software dijalankan di infrastruktur milik sendiri (server kampus), bukan cloud vendor.

// interface — abstraksi yang membuat swap murah
type StorageService interface {
    Upload(ctx, path, file io.Reader, size int64, contentType string) (string, error)
    GeneratePresignedURL(ctx, path, expirySeconds int) (string, error)
    Delete(ctx, path string) error
}

// pemilihan implementasi di router.go
